# 能力与限制

“已实测”表示开发者在真实平台上用自己的账号跑通过少量内容；“仅离线测试”表示只有用合成数据的自动测试。平台网页随时会变，任何一项都可能失效。

## 完整性

- 清单显示“未确认全部”时，表示没有拿到列表已经到底的证据，或者达到了扫描上限。已列出的内容可以照常下载，但不能据此认为已经覆盖全部历史。
- 重新扫描会从头再读一遍并合并已有清单，不支持从上次的位置续扫。
- 抖音桥接每次只发送你在页面上加载出来的那一批。

## 不做的事

- 不绕过验证码、不破解加密、不共享账号。遇到平台检查会停下来交给你处理。
- 不自动登录、不自动重试被拒绝的请求、不在后台定时运行。
- 不收集、不上传任何使用数据。
