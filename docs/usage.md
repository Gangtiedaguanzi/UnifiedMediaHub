# 统一媒体管理器：使用说明

第一次使用请先看 [新手教程](getting-started.md)。本文是各功能的说明和注意事项。

## 打开程序

- 从安装目录里的“统一媒体管理器”快捷方式打开。
- 右上角的**总开关**每次启动都是关闭的。打开后才能扫描、下载、登录；关闭会停止程序启动的所有浏览器和下载进程。
- 程序只能打开一个窗口。再次打开会切回已有窗口。

## 四个页面

| 页面 | 做什么 |
|---|---|
| 下载 | 粘贴链接或分享文案扫描；从账号读取收藏、喜欢、收藏夹、Telegram 聊天；勾选后下载 |
| 账号 | 登录各平台，查看当前确认的账号 |
| 历史 | 打开以前的清单、重新扫描、停止任务 |
| 设置 | 下载位置、分类、扫描上限、抖音 Edge 桥接、维护工具 |

## 登录

在“账号”页选择平台：

- **X、小红书**：点“打开专用登录”，在弹出的窗口里自己登录，完成后回到程序点“我已完成登录”。看到“本次登录已确认”才算成功。
- **Telegram**：点“扫码登录”，在手机 Telegram 打开“设置 → 设备 → 连接桌面设备”扫码。开了两步验证的，再在程序的密码框里输入密码。也可以点“手机号登录”：号码要带国家区号，例如 `+86` 后接手机号。
- **抖音**：抖音的列表通过你自己的 Edge 发送（见下文“抖音 Edge 桥接”），列表功能不需要在程序里登录抖音。单条抖音作品可以直接粘贴链接下载；如果提示需要登录，再在“账号”页用“打开专用登录”登录抖音。

验证码、两步密码只在程序自己的输入框里填写，不要发到聊天或网页里。遇到平台验证码、限流或账号不一致，程序会停下来等你处理，不会自动重试。

## 下载

### 单条作品

把作品链接或平台复制出来的整段分享文案粘贴到“下载”页，点“识别并扫描”，勾选后点“下载所选”。一段文案里有多个链接时，程序会提示你只保留一个。

### 我的收藏、喜欢、作者作品

在“从账号读取”里选平台和类型，点“扫描上述来源”。

- X：全部收藏（即书签）、我的喜欢。
- 小红书：全部收藏、我的喜欢（点赞），以及“选择收藏夹”读出的单个专辑。
- 抖音：这些列表都通过 Edge 桥接发送。

扫描只列出内容，不会自动下载。清单显示“未确认全部”时，表示程序没有拿到列表已经到底的证据，不代表一定缺了内容。

### Telegram 聊天

登录后点“Telegram 聊天”读取聊天目录（每页 100 个，最多 5000 个），可以搜索。选好聊天后点“扫描所选聊天”。也可以直接粘贴聊天、话题或单条消息的链接。文件、语音等暂不支持的消息会被跳过并默认不勾选。

### 扫描上限

“设置 → 扫描上限”：0 表示不限（最多 10000 条）。列表很长时扫描可能需要几分钟。

## 抖音 Edge 桥接

抖音会拦截程序自带的浏览器，所以抖音的喜欢、收藏、收藏夹和作者作品由你在自己的 Edge 里发送给程序：Edge 里装一个用户脚本，它读取你当前看到的列表，发送到本机的程序。

一次性配置（详细步骤见 [新手教程](getting-started.md#4-抖音-edge-桥接)）：

1. Edge 安装 Tampermonkey 扩展。
2. 在 Tampermonkey 里新建脚本，粘贴 `bridge/umh-douyin-bridge.user.js` 的全部内容并保存。
3. 在程序里打开总开关，“设置 → 抖音 Edge 桥接”勾选启用，点“应用”。
4. 点“复制”复制配对令牌。
5. 在 Edge 打开抖音，点页面上的“发送到统一媒体管理器”面板 →“配置配对”，填入端口（默认 47631）和令牌。

之后每次使用：

1. 在 Edge 里打开要下载的列表（我的喜欢、收藏、某个收藏夹或某位作者的主页）。
2. 在面板里点“读取当前页”，默认先读 20 条。需要更多时点“继续加载”。
3. 点“发送”。
4. 回到程序，核对清单，勾选后下载。

说明：

- 每批最多 1000 条。超过时，发送后再点“继续加载”，再发送下一批；同一页面已发送过的作品会自动跳过。
- 脚本不调用抖音接口、不读取 Cookie、不自动发送；只发送页面上已经显示的作品。
- 桥接只监听本机（127.0.0.1），拒绝来自网页的请求。关闭桥接开关或总开关就停止监听。
- 配对令牌只粘贴到你自己安装的桥接脚本里。怀疑泄露时点“重新生成”，旧令牌立即失效。
- 下载时如果抖音的链接已过期（提示 403/410），在 Edge 里重新发送这一批即可，已完成的文件会保留。
- 换了 Edge 个人资料或换了电脑，需要重新安装脚本并重新配对。

## 保存位置与文件夹

- 默认保存到 `%USERPROFILE%\Downloads\统一媒体下载`（即当前 Windows 用户的“下载”文件夹）。可以在“设置 → 下载位置”修改。
- “分类”可选，填了会多一级文件夹。只能是一级目录名，最多 40 个字符。
- 默认勾选“每次下载放进一个文件夹”：第一次下载时按“分类／平台／来源_名字_下载时间”建文件夹，例如 `x\我的喜欢_账号名_2026-11-19_2005`，文件平铺在里面。文件名是“发布时间_作者_标题_作品ID_序号”，按名称排序就是按时间排序。Telegram 是“发布时间_消息ID_序号”。
- 同一任务之后的补缺、继续下载都放回同一个文件夹。其他任务里已经下过的文件不会重复下载。
- 不勾选时，按“分类／平台／作者／日期_标题_作品ID／序号”保存，每条作品一个文件夹。

## 暂停、继续与重复

- “暂停”或关闭总开关会停止当前操作。已完成的文件保留，下次点“下载所选”会只补缺的。
- 已完成的文件按大小和 SHA-256 校验后复用；被移动、删除或损坏的会重新下载。
- 未完成的文件可能从头重新下载，不支持断点续传。
- 同一个文件出现在不同分类里时，优先用硬链接，不重复占用空间。

## 隐私与诊断

- 账号、登录会话、Cookie、配对令牌和下载历史都保存在 `<安装目录>\data\private`，只有当前 Windows 用户能访问。**不要把这个文件夹发给别人或上传到网上。**
- 程序只连接你使用的平台和本机地址，不会把任何数据发给作者或第三方。
- “设置 → 维护 → 导出诊断报告”生成的报告已经脱敏，不含账号、链接、标题或本机路径。在 GitHub 上反馈问题时，只附这份报告，不要附截图里的账号、私人内容或 `data` 文件夹。
- 程序没有开机自启、托盘常驻、系统服务、计划任务或自动更新。

## 空间

- 下载前会按已知大小检查剩余空间，并预留 64 MiB。Telegram 先下到临时位置再移入，需要大约两倍单批大小的空间。
- 缩略图缓存最多 128 MiB，可在“设置 → 维护”清理。

## 更新与回退

每个版本装在 `<安装目录>\releases\<版本号>`，互不覆盖；`data` 文件夹在版本之间共用。

1. 关闭程序。
2. 用新版本自带的工具校验：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File "<安装目录>\releases\<版本号>\maintenance\verify.ps1" -ReleaseRoot "<安装目录>\releases\<版本号>"
   ```

3. 切换快捷方式到新版本：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File "<安装目录>\releases\<版本号>\maintenance\activate.ps1" -InstallRoot "<安装目录>" -Version "<版本号>"
   ```

4. 需要回退时，用同样的命令把 `-Version` 换成旧版本号。

`-ExecutionPolicy Bypass` 只对这一次命令有效，不改系统设置。

## 已知限制

- 只支持 Windows 10/11 x64，界面只有中文。
- 平台网页经常变化，某个功能可能突然失效，需要等更新。
- 不支持分段 HLS/DASH 等非标准媒体。
- 其他电脑缺少 WebP 解码器时，缩略图显示占位图，不影响下载。
