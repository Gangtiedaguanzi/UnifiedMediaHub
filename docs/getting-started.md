# 新手教程

按顺序做一遍，大约 15 分钟。还没安装的话先看 [安装](install.md)。

每个人都要在自己的电脑上做这些配置：账号、登录状态和配对令牌只属于你这台电脑，不能也不应该从别人那里复制过来。

## 1. 第一次打开

1. 双击安装目录里的 `统一媒体管理器.lnk`。
2. 点右上角的**总开关**把它打开。每次启动程序时它都是关闭的；不打开就不会访问任何平台。
3. 到“设置”页看“下载位置”。默认是你的“下载”文件夹里的 `统一媒体下载`。想换位置就点“选择…”，然后点“保存设置”。

## 2. 先试一条

1. 在手机或网页上复制一条 X、抖音或小红书作品的分享链接（整段分享文案也可以）。
2. 回到程序“下载”页，粘贴到最上面的输入框，点“识别并扫描”。
3. 清单里出现这条作品后，勾选它，点“下载所选”。
4. 完成后点“打开文件夹”查看。

公开作品通常不需要登录。如果提示需要登录，先做下一步。

## 3. 登录 X、小红书、Telegram

到“账号”页，在“登录账号”里选择平台。

**X、小红书**

1. 点“打开专用登录”，会弹出一个单独的浏览器窗口。
2. 在这个窗口里正常登录你的账号（扫码、密码都可以）。
3. 回到程序，点“我已完成登录”。看到“本次登录已确认”就好了。

这个窗口和你平时用的浏览器是分开的，登录状态只保存在程序的 `data` 文件夹里。

**Telegram**

1. 点“扫码登录”，程序里会出现一个二维码。
2. 在手机 Telegram 打开“设置 → 设备 → 连接桌面设备”，扫这个二维码。
3. 开了两步验证的，在程序的密码框里输入密码，点“提交”。
4. 看到“本次登录已确认”就好了。

二维码过期了就再点一次“扫码登录”。也可以点“手机号登录”，号码要带国家区号（例如 `+86` 后接手机号）。

## 4. 抖音 Edge 桥接

抖音会拦截程序自带的浏览器，所以抖音的**喜欢、收藏、收藏夹、作者作品**要从你自己的 Edge 发送给程序。只需要配置一次。

### 4.1 安装 Tampermonkey

1. 打开 Edge，访问 Edge 扩展商店，搜索 **Tampermonkey**，点“获取”安装。
2. 如果 Tampermonkey 提示需要打开“开发人员模式”或“允许用户脚本”，按它的提示在 `edge://extensions` 里打开。

### 4.2 安装桥接脚本

1. 用记事本打开项目文件夹里的 `bridge\umh-douyin-bridge.user.js`（GitHub 仓库的 `bridge` 目录里也有）。按 `Ctrl+A` 全选，`Ctrl+C` 复制。
2. 在 Edge 工具栏点 Tampermonkey 图标 →“添加新脚本”。
3. 删掉编辑器里的默认内容，按 `Ctrl+V` 粘贴，再按 `Ctrl+S` 保存。
4. 在 Tampermonkey 的“已安装脚本”里确认“统一媒体管理器 · 抖音 Edge 桥接”是启用状态。

### 4.3 在程序里打开桥接

1. 确认总开关已打开。
2. 到“设置 → 抖音 Edge 桥接”，勾选“启用”。端口默认 47631，一般不用改；提示端口被占用时换一个 1024–65535 之间的数字。
3. 点“应用”。看到“桥接已开启：localhost:47631（仅本机）”就好了。
4. 点“配对令牌”旁边的“复制”。

设置页里的“安装说明”按钮也会一步一步显示这些步骤。

### 4.4 配对

1. 在 Edge 打开 www.douyin.com 并登录你的抖音账号（就是你平时在 Edge 里的登录）。
2. 页面右下角会出现“发送到统一媒体管理器”按钮，点它打开面板。
3. 点“配置配对”。第一个对话框填端口（默认 47631），第二个对话框粘贴刚才复制的令牌。
4. 面板显示“配对信息已保存。”就好了。

### 4.5 发送一个列表

1. 在 Edge 抖音里打开想下载的列表：个人主页的“喜欢”“收藏”，收藏里的某个收藏夹，或者某位作者的主页。
2. 在面板里点“读取当前页”，默认先读 20 条。
3. 想要更多就点“继续加载”，可以连续点。
4. 点“发送”。
5. 回到程序，“下载”页会出现这批作品。核对后勾选，点“下载所选”。

一批最多 1000 条。更多的话，发送后再点“继续加载”，再发送下一批；已经发送过的作品会自动跳过。

### 4.6 桥接常见问题

| 现象 | 处理 |
|---|---|
| 抖音页面上没有“发送到统一媒体管理器”按钮 | 确认脚本已启用，刷新页面；检查 Tampermonkey 是否要求打开“允许用户脚本” |
| 面板提示连不上管理器 | 程序的总开关和桥接开关都要打开；端口要和面板里填的一致 |
| 提示令牌错误 | 在程序里重新“复制”令牌，再在面板“配置配对”里粘贴 |
| 下载时提示 403 或 410 | 抖音的链接过期了。在 Edge 里重新读取并发送这一批，已完成的文件会保留 |
| 换了电脑或 Edge 个人资料 | 重新安装脚本并重新配对 |

令牌只粘贴到你自己安装的桥接脚本里，不要发给别人。怀疑泄露就在程序里点“重新生成”，旧令牌立即失效。

## 5. 下载收藏和喜欢

**X、小红书**：在“下载”页的“从账号读取”选择平台和类型（全部收藏、我的喜欢），点“扫描上述来源”。小红书的单个专辑用“选择收藏夹”。

**Telegram**：点“Telegram 聊天”读出聊天目录，可以搜索；选好后点“扫描所选聊天”。

扫描只列出内容，不会自动下载。勾选后点“下载所选”。清单很长时扫描要几分钟；扫描上限在“设置 → 扫描上限”，0 表示不限。

## 6. 遇到问题

- 任务停在“需要处理”：通常是平台要求验证码、限流或登录过期。按提示处理后再继续，不要连续反复重试。
- 程序打不开或报错：到“设置 → 维护 → 导出诊断报告”。报告已经脱敏，不含账号、链接或本机路径。
- 到 GitHub 反馈问题时，只附诊断报告。**不要**贴账号名、作品链接、带个人信息的截图，也不要上传安装目录下的 `data` 文件夹。

更多说明见 [使用说明](usage.md) 和 [能力与限制](capabilities.md)。
